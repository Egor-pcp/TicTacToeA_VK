# Журнал изменений (TicTacToeA_VK)

## [Unreleased] — 2026-11-07

### Changed
- **Оптимизация и консолидация документации:** проведена масштабная ревизия проектных документов для устранения избыточного расхода контекстных токенов ИИ-агентов.
- Вся ключевая информация из `ROADMAP.md`, `PROGRESS.md`, `TASKS.md`, `REQUIREMENTS.md`, `DECISIONS.md`, `TESTING.md` и `docs/` объединена в единую рабочую карточку проекта — **`TASKS_AI.md`**.
- Сокращены и актуализированы **`AGENTS.md`**, **`README.md`** и **`ARCHITECTURE.md`**.
- Зафиксированы результаты исследования официальных API платформы VK Mini Apps (алгоритм HMAC-SHA256 проверки параметров запуска, квоты VK Storage в 4 КБ, методы нативного перехода в сообщество и рекламные вызовы).

### Removed
- Удалены избыточные дублирующие документы (`ROADMAP.md`, `PROGRESS.md`, `TASKS.md`, `REQUIREMENTS.md`, `DECISIONS.md`, `TESTING.md`, `docs/README.md`, `docs/VK-MINI-APPS-RESEARCH.md`).

### Not Changed
- Игровой код (`index.html`, `style.css`, `script.js`, `game-logic.js`, `player-stats.js`) не изменялся.
- Сетевой прототип (`webrtc-prototype/`) сохранён без изменений.
- Зависимости не устанавливались и не изменялись.
