# Журнал изменений (TicTacToeA_VK)

## [Unreleased] — 2026-11-07

### Added
- **Клиентская интеграция онлайна (VK-003-005):**
  - Разработан клиентский сетевой модуль `OnlineServerClient.js` на базе EventTarget для прямого взаимодействия с Cloudflare Worker и Durable Objects;
  - Реализовано получение сессионного токена, подключение к очереди Matchmaker DO, экраны поиска, отмена поиска и автоматическое подключение к комнате Match DO;
  - Реализована отправка ходов с номерами `seq`, получение подтверждённых сервером ходов (`move_applied`), отображение победы, ничьей и поражения по авторитетным данным сервера;
  - Реализован механизм восстановления сессии (reconnect) при перезагрузке страницы через `sessionStorage`;
  - Интегрирован Development Mode для локального тестирования двух игроков (`dev_user_1` и `dev_user_2`) с переключателем в интерфейсе и поддержкой query-параметра `?dev_user=...`;
  - Написаны 7 автоматических тестов клиентского модуля (`server/test/online-client.test.js`), общее количество тестов расширено до 45 (все 45 пройдены).
- **Серверный онлайн-мультиплеер (VK-003-003, VK-003-004):**
  - Реализован `Matchmaker` Durable Object (`server/src/matchmaker.js`) для управления очередью случайного подбора игроков (FIFO-очередь в SQLite, отмена поиска `cancel_search`, защита от одновременных сессий одного пользователя, автоматический жребий 50/50 X/O, атомарная инициализация комнат);
  - Реализован `Match` Durable Object (`server/src/match.js`) для авторитетного управления сессией партии (серверная доска 3x3, 4x4, 5x5, валидация ходов и выигрышных линий через `server/src/game-rules.js`, контроль очередности, защита от дублей ходов по номеру `seq`);
  - Реализован контроль таймеров хода (30 сек) и окна переподключения (15 сек grace period) через встроенные Alarms Durable Objects;
  - Реализован механизм восстановления связи (reconnect) с отправкой актуального среза игры (`match_snapshot`) и уведомлений оппоненту;
  - Реализовано авторитетное сохранение результатов матчей и обновление рейтинга пользователей в Cloudflare D1 (`match_history`, `leaderboards`) с защитой от дублирования;
  - Добавлены 15 интеграционных тестов мультиплеера (`server/test/multiplayer.test.js`), общее число тестов расширено до 38 (все 38 пройдены).
- **Базовая серверная инфраструктура (VK-003-001, VK-003-002):**
  - Реализован Cloudflare Worker (`server/src/worker.js`) с эндпоинтом `POST /api/auth`, поддерживающим два режима: Development Mode (для `dev_user_1` и `dev_user_2`) и боевую проверку параметров запуска VK по алгоритму HMAC-SHA256;
  - Реализована проверка `vk_app_id` и срока актуальности параметров (`vk_ts`), защита от несанкционированного доступа;
  - Реализован эндпоинт `GET /api/leaderboard` для запроса топа рейтинга из Cloudflare D1;
  - Подготовлен защищённый маршрут WebSocket (`/ws`) с валидацией токена сессии;
  - Подготовлена начальная SQL-миграция для Cloudflare D1 (`server/migrations/0001_initial.sql`): таблицы `users`, `match_history`, `leaderboards`;
  - Написаны 18 автоматических тестов (`server/test/worker.test.js`, `server/test/vk-auth.test.js`, `server/test/token.test.js`), все тесты пройдены успешно;
  - Подготовлена конфигурация `server/wrangler.jsonc`, шаблон переменных `server/.dev.vars.example` и инструкция `server/README.md`.
- **Стратегия разработки в двух режимах (DEC-010):**
  - Принято решение владельца: разработка всего продукта ведётся в локальной среде до полной готовности перед переносом на платформу VK;
  - Спроектированы два режима работы приложения: `Development Mode` (локальный запуск, мок-адаптер VK Bridge, тестовые аккаунты, мультиплеер на 2 локальных окна) и `VK Mini Apps Mode` (боевая интеграция с VK Bridge и релизный бэкенд);
  - Создан раздел «Отложенные проверки в реальной среде VK Mini Apps» с четкими критериями и необходимыми доступами;
  - Пересмотрена дорожная карта: проект разделен на Блок 1 (локальная реализация 7 этапов) и Блок 2 (комплексные испытания в VK Mini Apps и публикация);
  - Реализован и протестирован модуль генерации и проверки сессионных игровых токенов (`server/src/token.js`).
- **Утверждённая архитектура онлайна (PH-002):**
  - Разделение серверных компонентов: Cloudflare Worker (шлюз и авторизация), `Matchmaker` Durable Object (очередь FIFO), `Match` Durable Object (изолированная сессия партии) и Cloudflare D1 (постоянная база данных профилей, результатов и рейтинга);
  - Спецификация защищённого потока аутентификации: проверка подписи HMAC-SHA256 и `vk_app_id` на сервере, выпуск короткоживущих игровых токенов; исключена передача сырых параметров запуска в WSS URL;
  - Механизм доверенных данных профиля через запрос к VK API (`users.get`) с сервисным ключом;
  - Реализован и протестирован модуль проверки параметров запуска на Web Crypto API (`server/src/vk-auth.js`);
  - Протокол сообщений WSS с поддержкой порядковых номеров ходов (`seq`) и защитой от дублирования;
  - Механизм Reconnect и настраиваемые предварительные тайм-ауты (ход 30 сек, grace period 15 сек).

### Changed
- **Оптимизация и консолидация документации:** проектная документация сокращена на 65% (с 867 до 305 строк) и объединена в компактную систему (`TASKS_AI.md`, `AGENTS.md`, `README.md`, `ARCHITECTURE.md`, `CHANGELOG.md`);
- Актуализированы `AGENTS.md`, `ARCHITECTURE.md` и `TASKS_AI.md` с учётом стратегии двух режимов и новой последовательности этапов.

### Removed
- Удалены устаревшие дублирующие реестры (`ROADMAP.md`, `PROGRESS.md`, `TASKS.md`, `REQUIREMENTS.md`, `DECISIONS.md`, `TESTING.md`, `docs/`).

### Not Changed
- Игровой код (`index.html`, `style.css`, `script.js`, `game-logic.js`, `player-stats.js`) сохранён без изменений;
- Директория `webrtc-prototype/` сохранена без изменений как эталонный рабочий прототип до завершения миграции.
