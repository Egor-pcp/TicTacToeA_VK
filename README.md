# TicTacToeA_VK

Браузерная игра «Крестики-нолики», подготавливаемая к публикации на платформе **VK Mini Apps**.
001
## Основные возможности
- **Поля:** 3×3 (3 в ряд), 4×4 (4 в ряд) и 5×5 (5 в ряд).
- **Режимы игры:** против компьютера и онлайн (случайный подбор соперника).
- **Сложность ИИ:** лёгкий, средний, сложный (минимакс для 3×3, эвристический поиск для 4×4 и 5×5).
- **Таймеры:** раздельный учёт времени текущего хода и общей длительности партии.
- **Статистика:** локальный учёт завершённых партий и рекордов по времени (`localStorage`).
- **Сетевой прототип:** экспериментальный матчмейкинг и WebRTC P2P на базе Cloudflare Worker / Durable Objects.

## Используемые технологии
- **Клиент:** чистый HTML5, CSS3, нативные ES6 JavaScript-модули (без сторонних фреймворков и сборщиков).
- **Сетевой прототип (`webrtc-prototype/`):** Cloudflare Worker, Durable Objects (SQLite), WebSocket, WebRTC DataChannel.

## Требования и запуск
1. **Основная игра и локальный мультиплеер (Development Mode):**
   - Запустите сервер: `cd server && npx wrangler dev` (сервер запустится на `http://localhost:8787`);
   - Запустите локальный статический сервер из корня проекта (например, `npx serve .` или `python -m http.server 3000`);
   - Откройте две вкладки браузера:
     - Окно 1: `http://localhost:3000/?dev_user=dev_user_1`
     - Окно 2: `http://localhost:3000/?dev_user=dev_user_2`
   - В обоих окнах нажмите «Онлайн» → «Начать поиск» — игроки мгновенно объединятся в партию через сервер!
   - В текущей версии локальная Dev-панель находится под подвалом игрового экрана. Для двух независимых окон также используйте URL с `?dev_user=dev_user_1` и `?dev_user=dev_user_2`.
2. **Сетевой WebRTC-прототип:** сохранён в каталоге [webrtc-prototype/README.md](./webrtc-prototype/README.md) как эталон.
