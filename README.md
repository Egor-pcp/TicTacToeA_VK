# TicTacToeA_VK

Браузерные крестики-нолики с несколькими размерами поля, уровнями сложности, таймерами и локальной статистикой.

- **Целевая платформа:** VK Mini Apps.
- **Цель:** подготовить существующую игру к Mini Apps и последовательно добавить платформенные возможности, онлайн-мультиплеер, пользовательские данные, рейтинг и рекламную монетизацию.
- **Текущий статус:** базовая игра и локальная статистика существуют; Git-репозиторий подготовлен локально; VK Mini Apps SDK и рекламная интеграция отсутствуют. Подробности — в [PROGRESS.md](./PROGRESS.md).

## Возможности игры

Подтверждённая базовая функциональность: режим против компьютера, уровни easy/medium/hard, поля 3×3, 4×4 и 5×5, таймеры партии/хода и локальная статистика в `localStorage`. Компьютер использует minimax для 3×3 и эвристический поиск для больших полей.

В коде также есть онлайн-режим на WebRTC с отдельным Cloudflare Worker для сигнализации и подбора пары. Это прототип, не VK-интеграция; подробности и ограничения описаны в [ARCHITECTURE.md](./ARCHITECTURE.md) и `webrtc-prototype/README.md`.

## Технологии и структура

- `index.html`, `style.css`, `script.js` — интерфейс и координация приложения.
- `game-logic.js` — правила и ходы AI.
- `player-stats.js` — локальная идентичность и статистика.
- `webrtc-prototype/` — браузерный WebRTC-клиент, тестовые страницы, Cloudflare Worker и Wrangler-конфигурация.
- `my avatar.JPG` — изображение страницы «О проекте».

Основное приложение использует HTML, CSS и нативные JavaScript-модули браузера. В корне нет `package.json` и команды запуска. Необходим браузер и HTTP-раздача корневых файлов; способ такой раздачи зависит от локального окружения и здесь не задаётся.

Для отдельного WebRTC-прототипа `webrtc-prototype/README.md` указывает Node.js не ниже 22 и npm; там описан запуск через `npm install` и `npm run dev`. Эти команды относятся только к прототипу.
