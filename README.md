# TicTacToeA_VK

Браузерная игра «Крестики-нолики», подготавливаемая к публикации на платформе **VK Mini Apps**.

## Основные возможности
- **Поля:** 3×3 (3 в ряд), 4×4 (4 в ряд) и 5×5 (4 в ряд).
- **Режимы игры:** против компьютера и онлайн (случайный подбор соперника).
- **Сложность ИИ:** лёгкий, средний, сложный (минимакс для 3×3, эвристический поиск для 4×4 и 5×5).
- **Таймеры:** раздельный учёт времени текущего хода и общей длительности партии.
- **Статистика:** локальный учёт завершённых партий и рекордов по времени (`localStorage`).
- **Сетевой прототип:** экспериментальный матчмейкинг и WebRTC P2P на базе Cloudflare Worker / Durable Objects.

## Используемые технологии
- **Клиент:** чистый HTML5, CSS3, нативные ES6 JavaScript-модули (без сторонних фреймворков и сборщиков).
- **Сетевой прототип (`webrtc-prototype/`):** Cloudflare Worker, Durable Objects (SQLite), WebSocket, WebRTC DataChannel.

## Требования и запуск
1. **Основная игра:** любой современный браузер. Запуск через любой локальный HTTP-сервер (например, `npx serve`, Live Server или Python `python -m http.server`), раздающий корень репозитория.
2. **Сетевой прототип:** Node.js >= 22, npm. Запуск описан в [webrtc-prototype/README.md](./webrtc-prototype/README.md).
